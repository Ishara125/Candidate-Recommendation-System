# Candidate Recommendation System

## Project Overview

This project is a Candidate Recommendation System that matches candidate CVs with suitable job roles based on skills, experience, education background, and CV-job description similarity.

The system preprocesses CVs and job descriptions, converts the text into vector representations, calculates similarity scores, and recommends the best-matching candidates for each job role.

## Main Features

- Read candidate CVs
- Read job descriptions
- Clean and preprocess text data
- Convert text into vector format
- Calculate similarity between CVs and job descriptions
- Rank and recommend top candidates

## Similarity Computation and Candidate Recommendation

This module calculates the similarity between processed candidate CVs and processed job descriptions. The cleaned text files are loaded from the `Data/processed_cvs` and `Data/processed_jobs` folders.

The system uses TF-IDF vectorization to convert candidate CVs and job descriptions into numerical vectors. Both CVs and job descriptions are transformed using the same TF-IDF vectorizer so they can be compared in the same feature space.

After vectorization, cosine similarity is used to measure how closely each candidate CV matches each job description. A higher cosine similarity score indicates a stronger match between the candidate profile and the job requirements.

For each job description, candidates are ranked in descending order based on their similarity scores. The system recommends the Top 5 best-matching candidates for each job description.

### Output File

The recommendation results are saved in the `results` folder:

```text

```

## Evaluation and Analysis

This module evaluates the recommendation results generated by the system.

The system recommendation output is taken from:

```text
results/recommendations.csv
```

The expected candidate matches are stored in:

```text
Data/evaluation_ground_truth.csv
```

The evaluation process compares the Top 5 recommended candidates with the expected candidate list for each job description.

The following metrics are calculated:

- Precision
- Recall
- F1-score

The evaluation results are saved in:

```text
results/evaluation_metrics.csv
results/evaluation_summary.txt
```

This analysis helps identify the strengths, weaknesses, and possible improvements of the Candidate Recommendation System.
